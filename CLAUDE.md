# Claude guidance for Archer

Before changing Archer, read [`AGENTS.md`](./AGENTS.md) for workspace-wide engineering boundaries and [`SPEC.md`](./SPEC.md) for current product behavior.

Use [`README.md`](./README.md) for setup, commands, demo accounts, and repository navigation. Keep product decisions out of `AGENTS.md`, and keep implementation/setup instructions out of `SPEC.md`.

When working in a nested project, also read that project's README and local guidance files. Keep `archer-app`, `archer-api`, and `archer-mobile` independent repositories, and run the relevant quality checks before committing.
